# Reproducibility and Statistics Foundation Report

This report documents the statistical and reproducibility foundation added to
ROSClaw-Darwin in Sprint 0 of the v1.2 implementation outline.

## 1. Metadata persistence for every Arena run

Every real Arena run now has a standard artifact directory generated by
`rosclaw_darwin/evaluation/reproducibility.py::persist_run_artifacts`.

### Required artifacts

| File | Purpose |
|---|---|
| `command.json` | The exact command / job that produced the run |
| `task.yaml` | Task specification used for the run |
| `policy.yaml` | Policy configuration used for the run |
| `result.json` | Full `EvaluationResult` |
| `summary.json` | Concise metrics + metadata |
| `episode_metrics.jsonl` | Per-episode scalar metrics |
| `phase_traces.jsonl` | Per-episode phase trace |
| `failure_signatures.jsonl` | Per-episode failure signature |
| `stdout.log` | Captured stdout |
| `stderr.log` | Captured stderr |
| `git_info.json` | Darwin commit / branch / dirty flag, Arena commit if available |
| `docker_info.json` | Image / image ID / container / GPU / driver |
| `environment_info.json` | Python version / timestamp / hostname |
| `seed_info.json` | Requested seed and seed-control notes |

### Seed control

`seed_info.json` records:

```json
{
  "requested_seed": 0,
  "arena_seed_controlled": true,
  "uncontrolled_randomness_notes": "Arena placement_seed is set but IsaacSim physics RNG is not fully isolated."
}
```

If Arena's internal RNG cannot be fully controlled, the notes field documents
the known uncontrolled randomness sources.

## 2. Statistical utilities

`rosclaw_darwin/analysis/statistics.py` provides:

| Function | Use |
|---|---|
| `bootstrap_ci(values)` | Bootstrap percentile CI for a mean |
| `bootstrap_delta_ci(a, b)` | Bootstrap CI for `mean(b) - mean(a)` |
| `wilson_ci(successes, n)` | Wilson score interval for a proportion |
| `two_proportion_z_test(...)` | Z-test for difference of proportions |
| `fisher_exact_test(...)` | Fisher exact test (exact for small tables, chi-square fallback for large) |
| `effect_size_absolute_delta(...)` | Absolute rate difference |
| `summarize_binary_condition(...)` | n_success / n_total / rate / Wilson CI / SE |
| `summarize_continuous_condition(...)` | mean / median / std / min / max / bootstrap CI |

### Design choices

- **Deterministic bootstrap**: default seed 42 so confidence intervals are
  reproducible across reruns.
- **Small-sample safety**: `fisher_exact_test` uses the exact hypergeometric
  distribution for tables with `n <= 100` and falls back to chi-square for
  larger tables where exact enumeration is expensive.
- **No hidden significance-only framing**: every report must show effect size
  and confidence interval, not just p-value.

## 3. Tests

- `tests/unit/test_statistics.py` — 18 passing tests covering Wilson CI,
  bootstrap CI/delta CI, z-test, Fisher exact, and binary/continuous summaries.
- `tests/unit/test_reproducibility_metadata.py` — tests for git info,
  environment info, seed info, and full artifact persistence.

```bash
ruff check rosclaw_darwin tests

```

Result: **18 passed**, lint clean.

## 4. Integration with run pipeline

The new `persist_run_artifacts` function is the recommended replacement for
`save_run_result` when full reproducibility metadata is required.  Existing
scripts that call `save_run_result` continue to work; new ablation scripts
(e.g. `run_lift_statistical_validation.py`) will call
`persist_run_artifacts` so that each condition/seed run produces the full
artifact set above.

## 5. Known limitations

- `collect_docker_info` relies on the `docker` and `nvidia-smi` CLI being
  available in the host environment.  If they are absent, the corresponding
  fields are `null` rather than failing the run.
- `arena_seed_controlled` is currently a manual flag; future work should
  verify that Arena's internal seed is actually honored by the IsaacSim
  environment.
- The bootstrap CI is a percentile interval (not BCa).  For modest sample
  sizes this is acceptable; for very skewed distributions a BCa correction
  may be added later.

## 6. Honest conclusion

ROSClaw-Darwin now has a reproducibility and statistical foundation that
supports:

1. Per-run artifact directories with git / Docker / environment / seed metadata.
2. Confidence intervals and significance tests for binary and continuous metrics.
3. Unit-tested helpers that can be reused by ablation scripts, dashboards, and
   reports.

This does not yet change any real Arena results; it provides the infrastructure
needed to make the next rounds of experiments auditable and statistically
interpretable.
